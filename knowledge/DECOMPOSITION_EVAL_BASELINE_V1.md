## 报警能力验证

评测器额外通过故障注入验证：

- 模拟模型多生成一条结构合法但无金标的任务时，precision 降为 50%，案例报告 `UNEXPECTED_TASKS`；
- 模拟模型引用原文不存在的 quote 时，拆解流水线拒绝结果，评测报告记录 `MODEL_OUTPUT_INVALID`；
- 损坏的 JSONL 会报告具体文件和行号。

## 结论边界

该基线证明以下内容没有回归：

- JSONL 数据集可以重复执行；
- 两阶段结构、Schema、证据门禁和任务硬规则能够正确处理金标输出；
- 指标能够识别额外任务和虚构证据；
- 昨天未完成事项、已完成事项排除、责任人和期限约束被锁定。

该基线**不证明真实模型语义质量为 100%**。replay 模式使用金标编译出的模拟模型输出，主要用于验证工程流水线和评测器。真实提示词质量必须在配置模型后执行：

```text
npm run eval:decomposition:live
```

并保存模型名称、供应商、模型版本、提示词哈希、失败案例、重试率、请求耗时和费用。
